## About Us

Aporixa is an independent research organization studying intelligent systems.
We run experiments, behavioral research, and adversarial testing to learn how
these systems behave, where they fail, and what those failures say about their
limits.

**Aporixa exists to investigate. Our commercial services exist to apply what we
learn.**

## What We Investigate

| Pillar                    | The question                                                                               |
| ------------------------- | ------------------------------------------------------------------------------------------ |
| **Behavioral research**   | How do models and agents actually behave, compared to how they are documented to behave?  |
| **Adversarial testing**   | Where do guardrails, defenses, and instructions break under deliberate pressure?          |
| **Systems in operation**  | What happens when autonomous tools act in real environments, including their own?         |

## How We Work

Every investigation follows the same loop:

```text
Build → Observe → Challenge → Learn → Rebuild
```

Each answer becomes the starting point for the next question. Every project also
has to leave behind at least one reusable asset: a methodology, test harness,
dataset, evaluation rubric, publication, or component. Some of these stay private
for confidentiality or security reasons. Others are published here.

## The Name

_Aporixa_ is a coined name, taken from the Greek **aporia**: the point where an
accepted explanation stops being enough and a real question begins.

The mark is an **open ouroboros**. A traditional ouroboros is a closed cycle.
Ours is deliberately left open, because the investigation is never complete.

## Work

Public repositories, tools, and publications will appear here as they are
released. Coming first:

- **The Warden**: a prompt-injection CTF with layered defenses on live models

  reasoned, did, and reported back
